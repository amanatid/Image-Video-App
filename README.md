# 🎬 Higgsfield AI Image & Video Generator

An AI-powered web application that leverages **Higgsfield AI** models to generate high-quality images from text prompts and convert static images into dynamic video clips/summaries.

---

## 🌟 Key Features

- **Text-to-Image Generation:** Generate detailed, customized images from natural language descriptions using Higgsfield AI endpoints.
- **Image-to-Video Transformation:** Transform generated or uploaded static images into cinematic video clips and motion summaries.
- **Prompt Customization:** Tweak camera motion, style presets, lighting, and aspect ratios.
- **Responsive UI:** Modern web interface for previewing, managing, and downloading generated images and videos.
